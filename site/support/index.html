자주 묻는 질문

로그인이나 회원가입이 필요한가요?

필요 없습니다. DayGrid는 iPhone에 로그인한 Apple 계정의 iCloud를 그대로 씁니다. 앱 안에서 따로 로그인하는 화면이 없습니다.

iCloud 동기화는 어떻게 켜나요?
  1. iPhone 설정 → [내 이름]에서 Apple 계정으로 로그인되어 있는지 확인합니다.
  2. 설정 → [내 이름] → iCloud의 iCloud를 사용하는 앱 목록(모두 보기)에서 DayGrid가 켜져 있는지 확인합니다.
  3. DayGrid의 설정 → 동기화에서 상태(최근 동기화 시각)를 볼 수 있습니다.

같은 Apple 계정으로 로그인한 기기끼리 자동으로 맞춰집니다. iCloud에 로그인하지 않아도 앱은 그대로 쓸 수 있고, 데이터는 그 기기에만 저장됩니다.

새 iPhone으로 바꾸거나 앱을 지웠다가 다시 깔면요?

같은 Apple 계정으로 로그인하고 DayGrid를 설치하면 iCloud에 있던 데이터를 자동으로 받아 옵니다. 데이터가 많거나 네트워크가 느리면 몇 분 걸릴 수 있습니다.

iCloud에서 로그아웃하거나 DayGrid의 iCloud를 끄면 어떻게 되나요?

iOS가 그 계정의 DayGrid 데이터를 이 기기에서 지웁니다. iCloud에 이미 올라간 데이터는 남아 있어서 다시 로그인하거나 켜면 돌아옵니다. 다만 아직 올라가지 않은 최근 변경은 사라질 수 있으니, 끄기 전에 앱의 설정 → 동기화에서 최근 동기화 시각을 확인해 주세요.

“동기화 오류”가 보여요.
  • “iCloud에 로그인되어 있지 않습니다”: 위의 iCloud 동기화 켜는 방법을 확인해 주세요.
  • “iCloud 저장 공간이 부족합니다”: 설정 → [내 이름] → iCloud에서 저장 공간을 확인해 주세요. DayGrid의 데이터는 글자뿐이라 아주 작습니다.
  • 그 밖의 오류: 앱의 설정 → 동기화 → 오류 내용 복사를 눌러 복사한 내용을 문의에 붙여 주세요. 일정 제목 같은 내용이 섞였는지 먼저 확인해 주세요.
알림이 오지 않아요.

iPhone 설정 → 앱 → DayGrid → 알림에서 알림이 허용되어 있는지 확인해 주세요. DayGrid의 설정 → 알림 → 시스템 알림 설정 열기로 바로 갈 수 있습니다. 알림은 일정 편집 화면에서 일정마다 켭니다.

연락처의 생일을 가져오려면?

DayGrid의 설정 → 생일에서 연락처에서 가져오기를 누릅니다. 처음 한 번 연락처 접근을 허용해야 합니다. 이름과 생일만 읽고, 음력 생일이 있으면 음력으로 가져옵니다.

잠금화면 위젯은 어떻게 넣나요?

잠금화면을 길게 누르고 사용자화 → 잠금 화면 → 위젯 자리를 눌러 DayGrid의 남은 반복 할일을 고릅니다. 오늘 해야 하는데 아직 하지 않은 반복 할일을 보여 줍니다.

공휴일이 달라요.

공휴일과 대체공휴일은 앱이 계산하고, 선거일과 임시공휴일은 하루에 한 번까지 받아 오는 보정 자료로 더합니다. 새로 정해진 임시공휴일이 보이지 않으면 문의로 알려 주세요.

데이터를 모두 지우고 싶어요.

앱에서 지운 일정은 이 기기와 iCloud에서 함께 지워집니다. 앱을 삭제해도 iCloud의 데이터는 남아 있으니, 모두 지우려면 iPhone 설정 → [내 이름] → iCloud → 저장 공간 관리(계정 저장 공간 관리)에서 DayGrid를 골라 데이터를 삭제해 주세요.
