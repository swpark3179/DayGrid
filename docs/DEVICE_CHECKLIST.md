# TestFlight 기기 확인 체크리스트

시뮬레이터와 UI 테스트로 확인하기 어려운 항목을 실제 iPhone에서 확인한다. 위에서부터 순서대로 따라 하면 된다.
Phase 4·5·6·8에서 미룬 기기 확인을 모았다(`docs/ROADMAP.md`의 "나중에 할 테스트").

- 1–6장: 2026-10-19 사용자가 모두 확인했다.
- 7장(iCloud, Phase 9): 준비(`docs/ICLOUD.md`)는 2026-10-20에 마쳤다. 스키마는 Development에 import했다.
  - 같은 날 TestFlight 실행 #3이 내보내기(서명)에서 실패해서, iCloud가 들어간 빌드는 아직 기기에 없다. 서명을 고친 뒤 확인한다.
- 8장(Phase 10)부터는 새 빌드에서 확인한다.
- 2026-10-21: 빌드 10에서 "iCloud 보내기 실패 … partialFailure(2)"가 보였다(사용자 확인). 같은 날 check 실행 #3에서 Production에는 아직 `Users`만 있었다. 7장은 CloudKit Console에서 Deploy한 뒤 확인한다.
  - 다음 빌드의 앱 기록에 `invalidArguments(12): Cannot create new type CD_PersonalHoliday in production schema`가 나왔다(사용자 확인). check 실행 #4(09:36Z)에서도 Production에는 `Users`만 있었다. 원인은 그대로 Deploy를 하지 않은 것이다.
- 2026-10-21: 9-5–9-8("나중에" → 달력)은 기기에서 놓기가 들어가지 않았다(사용자 확인). Phase 15에서 방식을 바꿨으므로 13장으로 확인한다.

- 준비
  - `main` 브랜치에서 `.github/workflows/testflight.yml`을 수동 실행한다(방법은 `docs/TESTFLIGHT.md`).
  - 처리가 끝나면 iPhone의 TestFlight 앱에서 새 빌드를 설치한다.
- 결과 기록: 문제가 있으면 항목 번호, 기대한 동작, 실제 동작을 적어 둔다. 화면 녹화가 있으면 더 좋다.

- [x] 3-3. 툴바로 바꾼 내용을 흔들기 또는 세 손가락 쓸기로 실행 취소할 수 있다.

- [x] 4-2. 설정 → 개인 휴일에서 기간을 만들면 달력에 빨갛게 보인다.
- [x] 4-3. 설정 → 생일 → 연락처에서 가져오기
  - 처음 누를 때만 연락처 권한을 묻는다.
  - "일부 연락처만 허용"(iOS 18)을 고르면, 고른 연락처의 생일만 들어온다.
  - 연락처에 음력 생일이 있으면 음력으로 들어오고, 달력에는 올해 양력 날짜에 🎂가 보인다.
  - 다시 가져오면 같은 사람이 둘로 늘지 않고, 연락처에서 바꾼 생일이 반영된다.
  - 권한을 거부하면 설정 앱에서 허용하라는 안내가 나온다.
- [x] 4-4. 30일 안에 생일이 있으면 달력 위에 배너가 보이고, 누르면 생일 목록이 열린다.
- [x] 4-5. 공휴일 보정 파일 원격 갱신(선택)

  - 다음 날 앱을 열면 그 날짜가 휴일로 보인다(하루에 한 번까지만 받아 온다). 확인한 뒤 시험용 항목을 지우고 `version`을 다시 올린다.

## 6. 알림 (Phase 8)
시각을 맞춰 기다려야 하는 항목이 많다. 6-2부터는 지금부터 15분쯤 뒤의 시간 일정을 만들어 확인하면 빠르다.
- [x] 6-1. 권한 요청 시점
  - 일정 편집에서 알림을 처음 켤 때만 권한을 묻는다.
  - 설정의 생일 알림이나 반복 할일 알림을 처음 켤 때도 같다.
  - 거부한 뒤에는 다시 묻지 않는다. 설정의 "시스템 알림 설정 열기"로 허용할 수 있다.
- [x] 6-2. 시간 일정: "정시"와 "10분 전"을 켜면 두 번 온다. 내용에 시작 시각이 보인다.
- [x] 6-3. 종일 일정: "당일 오전 9시", "전날 오전 9시"가 그 시각에 온다.
- [x] 6-4. 생일: 설정 → 알림 → 생일 알림을 "당일, 1일 전"으로 두면 생일 전날과 당일 오전 9시에 온다.
- [x] 6-5. 반복 할일: 알림을 켜면 주기가 시작되는 날 정한 시각에 한 번만 온다. 이미 체크한 주기는 오지 않는다.
- [x] 6-6. "완료" 동작
  - 할일 알림을 길게 눌러 "완료"를 누르면, 앱을 열지 않아도 그 할일이 완료된다.
  - 반복 할일 알림에서 누르면 그 주기가 체크된다.
- [x] 6-7. 알림을 누르면 앱이 열리고 그 날의 하루 상세가 보인다.
  - Phase 16부터 반복 할일 알림은 반복 탭을 연다(14-6).
- [x] 6-8. 앱을 쓰는 중에도 알림 배너가 보인다.
- [x] 6-9. 일정을 지우거나 시각을 바꾸면 예전 알림이 오지 않는다.
- [x] 6-10. 백그라운드 새로 고침(며칠 두고 확인)
  - 앱을 며칠 열지 않아도, 30일 뒤에 있던 일정의 알림이 때가 되면 온다.
  - 하루 한 번 백그라운드 새로 고침이 대기 알림을 다시 채우는지 보는 항목이다. iOS가 실행 시점을 정하므로 늦을 수 있다.

## 7. iCloud 동기화 (Phase 9)
먼저 `docs/ICLOUD.md`의 1–4단계를 끝낸다. 특히 CloudKit Console에서 Production 배포까지 해야 TestFlight 빌드가 동기화된다.
- [ ] 7-1. 이전 빌드 위에 업데이트해도 기존 일정, 할일, 카테고리, 생일, 반복 할일이 그대로 있다.
- [ ] 7-2. 설정 → 동기화 → iCloud가 잠시 뒤 "최근 동기화: 방금"이 된다.
  - "동기화 문제"가 보이면 그 아래 문구를 알려 준다. **오류 내용 복사**를 눌러 복사한 내용도 함께 붙여 넣는다.
  - 실패하고 1–2초 뒤에 복사하면 "앱 기록:" 아래에 CloudKit이 남긴 원인(예: `serverRejectedRequest(15): Cannot create new type CD_Item in production schema`)이 함께 들어간다.
- [ ] 7-3. 일정 하나를 만들고 1–2분 기다린 뒤 앱을 지우고 TestFlight에서 다시 설치한다.
  - 처음 열면 데이터가 비어 있다가 잠시 뒤 돌아온다.
  - 돌아오는 데 몇 분 걸릴 수 있다. 앱을 열어 둔 채 기다린다.
- [ ] 7-4. 다시 설치한 뒤 설정 → 카테고리에 기본 카테고리가 두 벌로 늘지 않는다. 바꿔 둔 이름과 색도 그대로다.
- [ ] 7-5. 비행기 모드에서 일정을 고치고, 비행기 모드를 끄면 동기화된다. 7-3 방법으로 확인할 수 있다.
- [ ] 7-6. 설정 앱에서 iCloud에서 로그아웃하면
  - 앱은 그대로 쓸 수 있다.
  - 설정의 동기화에 로그인 안내가 보인다.
  - 다시 로그인하면 동기화가 이어진다.
  - 이 항목은 선택이다. 로그아웃하면 다른 앱 데이터에도 영향이 있다.
- [ ] 7-7. (기기가 2대일 때, 같은 Apple ID) 한쪽에서 만든 일정, 반복 할일 체크, 생일이 다른 쪽에도 보인다. 반대 방향도 확인한다.
- [ ] 7-8. (기기가 2대일 때) 한쪽에서 알림을 켠 일정은 다른 쪽에서도 그 시각에 알림이 온다. 각 기기에서 알림 권한을 허용해 둬야 한다.

## 8. 달력·본문 개선 (Phase 10)
- [ ] 8-1. 달력 왼쪽 위 "2026년 10월"(또는 옆 화살표)을 누르면 "날짜로 이동"이 열린다.
  - 연도를 넘기고 달을 누르면 그 달로 바로 간다.
  - "오늘"을 누르면 이번 달로 돌아온다.
- [ ] 8-2. 개인 휴일은 날짜 숫자와 이름이 주황이다. 공휴일과 일요일은 빨강, 토요일은 파랑이다.
  - 개인 휴일이 공휴일과 겹치면 빨강으로 보인다.
- [ ] 8-3. 하루 상세의 기념일 섹션에서도 개인 휴일은 주황이다.
- [ ] 8-4. 오늘 해야 하는 반복 할일이 남아 있으면 "반복" 탭에 숫자 배지가 보인다.
  - 하나를 체크하면 숫자가 줄고, 모두 하면 배지가 사라진다.
  - 자정이 지나면 새 주기만큼 다시 늘어난다.
- [ ] 8-5. 하루 상세에서 본문이 있는 일정은 행 오른쪽에 문서 버튼이 있다.
  - 버튼을 누르면 읽기 화면(제목, 시간, 카테고리, 본문)이 열린다.
  - 행의 다른 곳을 누르면 예전처럼 편집 화면이 열린다.
- [ ] 8-6. 읽기 화면에서 본문 체크리스트를 누르면 켜지고 꺼진다. 닫았다 다시 열거나 편집 화면의 본문을 봐도 그대로다.
- [ ] 8-7. 할일이면 읽기 화면 제목 옆 체크박스로 완료를 켜고 끌 수 있다. 하루 상세 목록에도 바로 반영된다.

## 9. 끌어서 일정 넣기 (Phase 11)
- [ ] 9-1. 달력에서 날짜를 꾹 누르면 그 칸이 강조되고 진동이 온다. 그대로 다른 날짜까지 끌면 사이의 칸이 모두 강조된다.
- [ ] 9-2. 손을 떼면 새 일정 화면이 그 기간의 종일 일정으로 열린다. 위로·왼쪽으로 거꾸로 끌어도 된다.
- [ ] 9-3. 꾹 누른 뒤 움직이지 않고 떼면 그 날 새 일정 화면이 열린다.
- [ ] 9-4. 짧게 누르면 예전처럼 하루 상세가 열리고, 좌우로 밀면 예전처럼 달이 넘어간다. 꾹 누른 뒤에는 달이 넘어가지 않는다.
9-5–9-8은 Phase 15에서 13장으로 바뀌었다(탭을 바꾸지 않고 목록 위에 달력을 덮는다).
- [ ] 9-5. "나중에"에서 항목을 오래 누르면 항목이 손가락에 붙고 달력 탭으로 바뀐다.
  - 날짜 위에서 손을 떼면 그 날로 들어간다. 시간 일정이었다면 원래 시각과 길이로 들어간다.
  - 놓으려는 칸이 강조된다.
- [ ] 9-6. 끄는 중 화면 왼쪽·오른쪽 끝에 머무르면 이전·다음 달로 넘어간다.
- [ ] 9-7. 달력 밖(탭 막대 등)에서 놓거나 취소하면 항목은 "나중에"에 그대로 있다.
- [ ] 9-8. "나중에"의 편집(순서 바꾸기) 중에는 달력으로 바뀌지 않고 순서만 바뀐다.

## 10. 잠금화면 위젯 (Phase 12)
먼저 `docs/WIDGET.md`의 1–3번(App Group, 앱 App ID, 위젯 App ID)을 끝낸다.
- [ ] 10-1. 잠금화면 사용자화에서 DayGrid "남은 반복 할일"을 찾을 수 있다. 목록형, 동그라미, 한 줄 모양이 모두 있다.
- [ ] 10-2. 목록형에는 오늘 해야 하는데 아직 안 한 반복 할일이 반복 탭 순서대로 최대 3개 보인다.
  - 더 많으면 2개와 "외 n개"가 보인다.
  - 없으면 "남은 반복 할일 없음"이 보인다.
- [ ] 10-3. 앱에서 하나를 체크하면 잠시 뒤 위젯에서 빠진다. 알림의 "완료"로 체크해도 빠진다.
- [ ] 10-4. 자정이 지나면 새 주기가 온 반복 할일(예: 매일)이 다시 나타난다. 앱을 열지 않아도 된다.
- [ ] 10-5. 위젯을 누르면 앱이 열리고 "반복" 탭이 보인다.
- [ ] 10-6. 반복 할일을 중지하거나 지우면 위젯에서 사라진다.

## 11. 하루 상세 타임라인 (Phase 13)
- [ ] 11-1. 설정 → 하루 상세 → 보기 방식을 "타임라인"으로 바꾸면 업무 시작·종료 시간이 나타난다. "목록"으로 돌리면 하루 상세가 예전 모양으로 돌아온다.
- [ ] 11-2. 업무 시간을 바꾸면 하루 상세 타임라인의 위아래 끝이 바뀐다.
  - 종료 시간은 시작보다 30분 이상 늦게만 고를 수 있다.
  - 시작을 종료보다 늦게 옮기면 종료가 시작 + 1시간으로 따라간다.
- [ ] 11-3. 시간 일정과 시간 할일이 시각 위치에 블록으로 놓인다. 종일·기간 일정과 시간 없는 할일은 그 아래 목록에 있다.
  - 반복 할일은 Phase 16부터 하루 상세에 없다.
- [ ] 11-4. 업무 시간 밖의 일정(예: 아침 7시, 저녁 7시)이 있는 날은 그 시각까지 타임라인이 늘어나고, 업무 시간 밖은 옅은 회색이다. 없는 날은 업무 시간만 보인다.
- [ ] 11-5. 시간이 겹치는 일정은 나란히 놓이고, 짧은 일정(15분, 0분)도 제목이 보인다.
- [ ] 11-6. 빈 곳을 누르면 그 시각(30분 단위)부터 1시간짜리 새 일정 화면이 열린다. 블록 오른쪽 여백을 누르면 겹치는 시각에도 만들 수 있다.
- [ ] 11-7. 블록을 누르면 편집 화면이 열리고, 꾹 누르면 복제·나중에·삭제 메뉴가 나온다. "나중에"로 보내면 "나중에" 목록 맨 위에 들어간다.
- [ ] 11-8. 할일 블록의 체크박스로 완료를 켜고 끌 수 있다. 본문이 있으면 블록의 문서 버튼으로 읽기 화면이 열린다.
- [ ] 11-9. 밤을 넘는 일정(예: 22:00–02:00)은 첫날 22시부터 자정까지, 다음 날 자정부터 2시까지 보인다.

## 12. 달력 막대, 하루 상세에서 옮기기 (Phase 14)
- [ ] 12-1. 하루 안에 끝나는 시간 일정(예: 10:00–11:00 회의)도 달력에 카테고리 색 막대로 보인다. 같은 날의 종일 일정 막대 아래에 시각 순으로 놓인다.
- [ ] 12-2. 하루 안에 끝나는 시간 할일은 예전처럼 색 점과 제목으로 보이고, 완료하면 취소선이 그어진다.
- [ ] 12-3. 하루 상세의 일정이나 할일 행을 꾹 누르면 진동이 오고, 시트가 아래로 작아져 달력이 보인다. 손가락 위에 제목과 "→ 10월 24일 (토)" 같은 놓을 날짜가 따라온다.
- [ ] 12-4. 다른 날짜 위에서 떼면 그 날로 옮겨지고 시트가 닫힌다.
  - 시간 일정은 시각과 길이가 그대로다.
  - 여러 날 일정은 연 날짜에서 놓은 날짜까지의 차이만큼 통째로 옮겨진다.
  - 할일의 완료 표시는 그대로다.
- [ ] 12-5. 같은 날, 달력 밖(아래의 작은 시트, 탭 막대), 또는 거의 움직이지 않고 떼면 옮기지 않고 시트가 원래 높이로 돌아온다.
- [ ] 12-6. 끄는 중 화면 왼쪽·오른쪽 끝에 머무르면 이전·다음 달로 넘어가고, 그 달의 날짜에 놓을 수 있다.
- [ ] 12-7. 행을 짧게 누르면 예전처럼 편집 화면이 열린다. 위아래로 밀면 목록이 스크롤되고, 좌우로 밀면 삭제·복제·나중에 버튼이 나온다. 체크박스와 본문 버튼도 예전처럼 동작한다.
- [ ] 12-8. 옮긴 일정에 알림을 켜 두었으면 새 날짜·시각에 알림이 온다.
- [ ] 12-9. 타임라인 보기에서 본문이 있는 블록의 문서 버튼이 예전보다 크고, 30분짜리 짧은 블록에서도 누르기 쉽다.

## 13. "나중에" 키보드, 꾹 눌러 달력에 넣기 (Phase 15)
- [ ] 13-1. "나중에" 입력창에 쓰는 중 목록의 빈 곳이나 제목 줄을 누르면 키보드가 내려간다. 행을 누르면 키보드가 내려가고 편집 화면이 열린다.
  - 입력창 안을 누르면 키보드가 그대로이고 커서만 옮겨진다.
  - 엔터를 치면 예전처럼 들어가고 이어서 쓸 수 있다.
- [ ] 13-2. 항목을 꾹 누르면 진동이 오고, 탭은 "나중에" 그대로인 채 목록 위에 이번 달 달력이 덮인다. 손가락 위에 제목과 "→ 10월 24일 (토)" 같은 넣을 날짜가 따라오고, 그 칸이 강조된다.
- [ ] 13-3. 날짜 위에서 떼면 그 날로 들어가고, 달력 탭으로 바뀌어 그 달이 보인다(사용자 결정 2026-10-21). 항목은 "나중에"에서 빠진다.
  - 미뤄 둔 시간 일정이었다면 원래 시각과 길이로 들어간다.
- [ ] 13-4. 끄는 중 화면 왼쪽·오른쪽 끝에 머무르면 덮개 달력이 이전·다음 달로 넘어가고, 그 달의 날짜에 넣을 수 있다. 넣은 뒤 달력 탭도 그 달을 보여준다.
- [ ] 13-5. 달력 밖(위쪽 안내 줄, 탭 막대)에서 떼거나 거의 움직이지 않고 떼면 아무것도 바뀌지 않고 "나중에" 목록으로 돌아온다.
- [ ] 13-6. 짧게 누르면 예전처럼 편집 화면이 열린다. 위아래로 밀면 목록이 스크롤되고, 좌우로 밀면 삭제·날짜·완료 버튼이 나온다.
- [ ] 13-7. 편집(순서 바꾸기) 중에는 덮개 달력이 나오지 않고 순서만 바뀐다. 편집 밖에서 꾹 눌러도 순서가 바뀌지 않는다. 완료한 항목은 꾹 눌러도 달력이 나오지 않는다.

## 14. 테마, 달력에서 반복 할일 빼기 (Phase 16)
- [ ] 14-1. 설정 → 화면 → 테마를 "다크"로 바꾸면 iPhone이 라이트 모드여도 앱이 바로 어두워진다. 다음 화면도 함께 어두워진다.
  - 탭 막대, 상태 막대
  - 하루 상세 시트, 편집 화면
  - 본문 미리보기, 꾹 눌러 옮길 때 손가락 위의 미리보기
- [ ] 14-2. "라이트"로 바꾸면 iPhone이 다크 모드여도 앱이 밝다.
- [ ] 14-3. "시스템"으로 되돌리면 앱을 다시 열지 않아도 iPhone 설정을 따른다. 제어 센터에서 다크 모드를 켜고 끄면 앱도 따라 바뀐다.
- [ ] 14-4. 앱을 완전히 닫았다가 다시 열어도 고른 테마가 그대로다.
- [ ] 14-5. 반복 할일을 체크해도 달력의 날짜 칸에 ✓가 생기지 않는다. 하루 상세(목록, 타임라인)에도 "반복 할일" 섹션이 없다.
  - 반복 탭, 탭 배지, 잠금화면 위젯은 예전과 같다.
- [ ] 14-6. 반복 할일 알림을 누르면 앱이 열리고 "반복" 탭이 보인다.
  - 일정·할일·생일 알림을 누르면 예전처럼 그 날의 하루 상세가 보인다.
  - 알림의 "완료" 동작은 예전과 같다.

## 15. UI·모션 개선 (Phase 17)
- [ ] 15-1. 달력에서 날짜를 꾹 누르면 숫자 둘레에 파란 링이 차오르고, 다 차는 순간 진동과 함께 기간 고르기가 시작된다.
  - 좌우로 밀어 달을 넘기면 링이 보이지 않거나 바로 사라진다.
  - 짧게 누르면 예전처럼 하루 상세가 열린다.
- [ ] 15-2. 끄는 동안 고른 날들이 한 줄에 이어진 둥근 띠로 보이고, 칸이 늘 때 띠가 부드럽게 자란다. 손가락 위에 "10월 12일 – 16일 · 5일"처럼 기간이 보인다.
  - 주를 넘기면 띠가 다음 줄로 이어진다(이어지는 쪽 모서리는 평평하다).
- [ ] 15-3. 하루 상세에서 꾹 눌러 옮길 때
  - 미리보기가 살짝 커지며 들어 올려진다.
  - 놓을 칸에 띠가 보이고, 칸이 바뀔 때 따라 움직인다.
  - 놓으면 미리보기가 그 칸으로 줄어들며 사라진다. 그 칸이 한 번 빛나고, 옮긴 막대가 튀어 들어온다.
  - 달력 밖에서 놓으면 미리보기가 시작한 자리로 돌아가며 사라진다.
- [ ] 15-4. "나중에" 항목을 꾹 눌러 달력에 넣으면, 달력 탭에서 넣은 날이 한 번 빛나고 막대가 튀어 들어온다.
- [ ] 15-5. 먼 달(예: 내년 3월)에서 "오늘"을 누르면 사이의 달을 넘기지 않고 바로 이번 달이 되고, 오늘 칸이 한 번 빛난다. 바로 옆 달에서는 예전처럼 넘어간다. 연·월 시트의 "오늘"도 같다.
- [ ] 15-6. 달을 넘기면 제목의 숫자가 넘긴 방향으로 굴러간다. 연·월 시트에서 해를 넘겨도 숫자가 굴러간다.
- [ ] 15-7. 하루 상세에서 밀어서 삭제, 복제, 나중에를 하면 아래쪽에 토스트가 4초 동안 뜬다. "실행 취소"를 누르면 가벼운 진동과 함께 원래대로 돌아온다.
  - 지운 일정은 제목, 날짜, 시각, 카테고리, 본문, 알림, 완료 표시가 그대로 돌아온다.
  - 타임라인 블록의 꾹 누르기 메뉴(복제, 나중에, 삭제)도 같다.
  - "나중에" 탭에서 밀어서 지울 때도 같다. 키보드가 올라와 있으면 토스트가 키보드 위에 뜬다.
  - VoiceOver를 켜면 토스트 문구를 읽어 주고 8초 동안 남는다.
- [ ] 15-8. 할일과 반복 할일을 체크하면 체크 기호가 바뀌며 튀고, 완료로 바뀔 때만 진동이 온다. 반복 탭의 "이번 달 n/m" 숫자가 굴러가고 옆의 링이 찬다.
- [ ] 15-9. 앱을 처음 쓸 때 팁이 한 번씩 보인다.
  - 달력: "꾹 눌러 기간 일정 만들기"
  - 일정이 있는 하루 상세: "꾹 눌러 다른 날로 옮기기"
  - "나중에": "꾹 눌러 달력에 넣기"
  - 팁의 ×를 누르거나 그 동작을 한 번 해 보면 다시 나오지 않는다. 앱을 다시 열어도 마찬가지다.
- [ ] 15-10. 일정 편집과 반복 할일 편집에서 카테고리가 색 칩으로 보인다. 칩을 누르면 선택 표시가 미끄러져 옮겨 간다. 저장하면 달력 막대 색이 바뀐다. "없음"을 고르면 회색이다.
  - 일정 편집에서 "날짜 지정"과 "종일"을 켜고 끄면 아래 줄이 부드럽게 열리고 닫힌다.
- [ ] 15-11. "나중에" 입력창에 쓰고 엔터를 치면 새 행이 목록 맨 위로 미끄러져 들어오고, 입력창 오른쪽에 "넣음"이 잠깐 보이며 가벼운 진동이 온다. 할일을 완료하면 행이 "완료" 묶음으로 옮겨 간다.
- [ ] 15-12. 설정 → 손쉬운 사용 → 동작 → 동작 줄이기를 켜면 링, 띠, 미리보기, 토스트가 크기나 위치를 바꾸지 않고 나타나고 사라지기만 한다. 기능은 그대로다.
